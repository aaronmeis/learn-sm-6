Tailored prompts — Raytheon SM-6

Pack override for w8-prepare (T1 to T4). Every prompt stays at the open-source, architecture level of the spine page.

T1

Using only the sources, write a working briefing for a practitioner learning Raytheon SM-6. Define the core vocabulary (RIM-174 ERAM, active and semi-active homing, blast-fragmentation versus hit-to-kill, endo- versus exo-atmospheric, CEC, NIFC-CA, Aegis Baseline 9, Mk 41, Typhon, AIM-174B). Structure the system as Sense, Share, Decide, Act, Assess, Sustain, and present the variants as a family tree. Do not estimate classified parameters such as range, engagement envelope, seeker performance, or probability of kill. Mark where the sources are silent.

T2

Using only the sources, explain the key mental models and distinctions for Raytheon SM-6: the kill web versus the missile, layered defense by phase (SM-3, SM-6, GPI, ESSM, SM-2), engage-on-remote versus launch-on-remote, software upgrades versus kinematic upgrades, and demonstration versus operational test. For each, give a common failure mode in how people talk about SM-6. Cite source language when available. Mark silence.

T3

Using only the sources, produce a practice playbook for grading public claims about Raytheon SM-6. For each named event in the sources (the 2016 NIFC-CA intercept, the 2017 tri-mission tests, FTM-31 E1a, FTM-32, Valiant Shield 2024, FTX-40, Talisman Sabre 2025), state what it demonstrated and what it did not establish. Then write a ten-claim self-test with answers, and a falsification test for fluency that is only memorized specifications. Mark silence.

T4

Using only the sources, catalog edge cases and traps when analyzing Raytheon SM-6: unofficial range figures, unit-cost bases, contract ceilings versus appropriations, the Block IB schedule, hypersonic-defense claims, combined expenditure figures, and the DOT&E findings on contested-spectrum and cyber survivability. For each trap give the symptom, the likely cause, and the mitigation the sources support. Keep any countermeasure discussion at the level of the broad classes the sources name; do not add techniques. Mark silence.
